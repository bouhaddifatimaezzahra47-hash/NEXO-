# NEXO 

## Présentation:
NEXO est une plateforme e-commerce où l'on peut acheter et vendre des produits en ligne.
## Demo:
[Screen recording 2026-09-26 14.59.53.webm](https://github.com/user-attachments/assets/321731a4-d90e-4ebf-b69d-bb42b0f9166d)
## Fonctionnalités:
 - Authentification(inscription page + login page+ se déconnecter + supprimer le compte )
 - page d'acceuil avec catalogues des produits
 - vendre ton produit
 - un panier (ajout et suppression d'articles)
 - recherche de produits par nom
 - recherche par catégories
## Technologies utilisées:
  ### - backend:
            - Django /Django REST Framework
            - django-cors-headers pour la gestion du CORS
            - DRF permissions 
            - Pillow pour la gestion des images
            - SQLite
  ### - frontend:
            - Vue 3(JavaScript)
            - Vite
            - Vue Router
            - Axios
            - Bootstrap
